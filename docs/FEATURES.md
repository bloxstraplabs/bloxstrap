# reistrap features

Everything reistrap can do, as of v1.1.1.

## Settings window

- Collapsible sidebar with pages grouped by dividers
- Search any setting and jump straight to it
- Page headers with an icon, title and description
- Bottom bar with Save and Launch Player, a dropdown for Save and Launch Studio and Test mode, Restart, Save and Close
- Version number with an update button when a new version is out
- Remembers its size and position
- Credits and About windows

## First launch and updates

- Installer
- Welcome setup for fresh installs only, with an animated intro, import from Bloxstrap, Fishstrap, Froststrap or Voidstrap, theme and accent with live preview, the main features as tiles, and a performance preset (leave it to Roblox, More FPS, Best quality)
- Optional automatic updates when launching Roblox, including pre-releases
- Checks for new versions whenever settings opens and offers to install them
- Anonymous analytics that can be turned off

## Integrations

- Activity tracking
- Server location (RoValra, with ipinfo as a backup), server uptime and a popup when you join
- Don't exit to desktop app
- Auto-rejoin after idle kicks, lost connections, server shutdowns or failed teleports, with an attempt limit and a delay
- Tray icon with playtime counter, server details, game history, invite link, close Roblox, open log, Discord status toggle and SOCD toggle
- Choose what double-clicking the tray icon does
- Block Roblox screenshots and video recordings
- Discord Rich Presence with game name and icon, join and game page buttons, your Roblox account, game name in status, "Using reistrap", and a custom status per game
- Games can set Discord status through BloxstrapRPC
- Roblox Studio Rich Presence with game name, game icon, play testing status and a game page button
- Show the script you're editing in Studio Rich Presence, with its name, line count and an icon for server, local or module scripts, through a small Studio plugin
- Game window control for games made for Funkstrap, like Project: Afternight: move and resize, title, transparency, color, wallpaper, taskbar and desktop icons, with a permission prompt per game, an allow-all option, monitor choice, update rate and a permissions reset
- Custom integrations that launch with Roblox, close with Roblox, or run only in a specific game

## Bootstrapper

- Multiple Roblox instances, with an optional confirmation prompt
- Background updates and force reinstall
- Roblox CPU priority, lower priority in the background, and CPU core selection
- Close Roblox's crash handler
- Memory trimmer with a threshold and interval
- Allow unsupported Roblox languages
- Cache cleaner with a schedule, folder choices and Clean now
- Player and Studio channels with a Check button
- Find channels: check which known Roblox channels are public and their versions, and switch to one
- Block Roblox updates and use a fixed install folder
- Choose what happens when a launch link asks for a different channel
- Pin a Roblox Player or Studio version
- Parallel downloads

## Playtime

- Playtime per game with totals
- Session recap when you leave a game
- Break reminder
- Performance log with CPU, GPU and memory per session, recent sessions and small graphs

## Quick Play

- Search games by name, link or place ID
- Browse a game's places and public servers and join any of them
- Rejoin your last public server
- Continue playing your recent games
- Recent games in the launch menu

## Region Selector

- Better matchmaking: Play joins a server near you, with a preferred region or Automatic, and an optional random pick
- Browse a game's servers by city with uptime, join and load more

## Mods

- Presets: mouse cursor, old avatar editor background, old character sounds, preferred emoji type
- Custom cursor, Shift Lock icon, death sound and font
- Mod packs (import and export)
- Cursor sets (save, apply, delete)
- Color mods with a multi-color gradient, angle and live icon preview, for Roblox UI icons, cursors, Shift Lock icon and emote wheel
- Custom skybox packs
- Apply mods to Roblox Player and/or Studio
- Compatibility settings and open the mods folder

## Appearance

- Theme (System, Light, Dark), language and accent color
- Window effect (Mica, Acrylic, Aero, None)
- App font
- Background image or gradient with strength and fit
- Smooth scrolling in every window
- Turn off animations, which also turns off smooth scrolling
- Loading window style, custom themes with an editor, import and export, theme cycling on every launch or every hour, day or week, icon and title

## Engine Settings (Fast Flags)

- Fast Flag manager toggle
- Presets: MSAA, display scaling fix, texture quality, rendering mode, graphics quality override, pause voxelizer, gray sky, disable grass, mesh detail
- All allowlisted flags
- Fast Flag editor with a warning for flags that aren't on Roblox's allowlist
- Fast Flag profiles (save and load)
- Reset everything

## Roblox

- Game settings: frame rate cap, graphics quality, fullscreen, master, Studio, voice chat and party volume, camera sensitivity, invert camera, controller vibration, menu background opacity, text size, vignette, reduced motion, performance stats, player list, chat and VR mode
- Lock the settings file, open it, import and export it
- Custom window title, or game name and player count in the title
- Borderless windowed
- Game icon, classic Roblox logos or your own image as the Roblox and Studio window icon
- Roblox app theme and run in the background
- Crosshair overlay with style, color, size, thickness and gap
- SOCD (snap tap) for WASD, ZQSD, ESDF or arrow keys, with last pressed, first pressed or neither

## Game profiles

- Per game Fast Flag profile, frame rate cap, graphics quality, crosshair and Discord status

## Shortcuts

- Desktop and Start Menu shortcuts for Roblox, Studio and reistrap settings
- Extract Roblox icons to a folder
- Game shortcuts by name, link or place ID, optionally to a specific server or private server, with the game's icon

## reistrap

- Automatic updates and pre-releases
- Reset all settings
- Analytics toggle
- Backup and restore everything to one file
- Import settings, Fast Flags and mods from another bootstrapper
- Export diagnostic data and view logs
