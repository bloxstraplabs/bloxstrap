# LumiStrap 0.1.3

## 1. Novedades

- **Modos de renderizado:** elige entre Automático, Direct3D 11 y Vulkan.
- **Detalle de mallas:** ajusta el nivel de detalle geométrico.
- **Calidad FRM:** agrega un control para el nivel de calidad del administrador de fotogramas.
- **Revisión de actualizaciones:** muestra la versión y las notas antes de actualizar; permite posponer la actualización.
- **Copia de configuración:** guarda un perfil automático antes de actualizar y conserva hasta cinco copias recientes.

## 2. Cambios

- **Instalador de Windows:** se distribuye como Setup; extrae los archivos temporalmente y abre el asistente de LumiStrap.
- **Avisos de FastFlags:** la interfaz aclara que Roblox puede limitar o ignorar algunas flags.
- **Privacidad:** la telemetría queda desactivada de forma predeterminada.

## 3. Errores solucionados

- El instalador ahora copia también las DLL, los archivos de configuración y los recursos de idioma necesarios para abrir LumiStrap.
- La desinstalación ahora limpia esos archivos y carpetas de idioma junto con la aplicación.
- Se evita ejecutar migraciones antiguas de Bloxstrap sobre la instalación de LumiStrap.
